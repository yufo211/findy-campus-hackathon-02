# Ogiri Answer

大喜利のお題に対して、短く、意外性があり、説明不要で笑える回答を作る。

## Goal

「正しい回答」ではなく「予想を少し裏切る回答」を優先する。原則として回答は1文にし、読んだ瞬間に情景が浮かぶ具体性を持たせる。

## Principles

- 普通の答えから少しだけズラす。
- 長い説明を避ける。原則1文。
- お題の単語をそのまま繰り返すだけの回答を避ける。
- ダジャレだけに逃げない。
- 「AI」「ChatGPT」「実は〜だった」など頻出テンプレを乱用しない。
- 意味不明すぎるシュールさを避ける。
- 情景、行動、物、距離、時間、役職、金額などの具体的なディテールを優先する。
- 既視感のある定番ネタより、少し変な生活感や妙に現実的な違和感を選ぶ。

## Generation Procedure

1. お題の「普通ならどう答えるか」を3つ考える。
2. 普通の回答からズラす軸を選ぶ。
   - スケールを変える。
   - 立場を逆転する。
   - 異常に具体的にする。
   - 別ジャンルの常識を持ち込む。
   - 隠れていた本音を露出させる。
   - 目的と手段を入れ替える。
   - 小さすぎる事情を大げさに扱う。
3. 異なる方向性で10案生成する。
4. 以下の基準で内部評価する。
   - 意外性
   - 分かりやすさ
   - 短さ
   - 情景の強さ
   - 既視感の少なさ
   - お題への密着度
5. 上位3案だけ出力する。

## Good Answer Heuristics

- 読者が「その場面ありそう」と思える程度に具体的にする。
- 抽象的な形容詞ではなく、行動や状況で笑わせる。
- オチは最後に置く。ただし不自然に引っ張らない。
- お題の中心語をなぞるだけでなく、周辺の小物、制度、係、時間帯、空気感を使う。
- 強い1案がある場合でも、方向性の違う3案にする。

## Bad Patterns

避ける:

- 「こんな○○は嫌だ → AIが搭載されている」
- 「校長先生の話が3時間続く」
- 「全部○○だった」
- 「実は夢だった」
- 「逆に○○」
- 説明しないと意味が通らない内輪ネタ
- 属性、容姿、国籍、性別、障害、年齢などを下げる笑い

理由:

- AIネタへの置換だけでは意外性が弱い。
- 長時間の校長先生ネタなどは既視感が強すぎる。
- 夢オチ、実は系、全部系は便利だが安く見えやすい。
- 攻撃対象を作る笑いは、面白さより不快さが先に立つ。

## Output

指定がなければ上位3案だけを番号付きで出力する。

```text
1. ...
2. ...
3. ...
```

解説は要求された場合のみ行う。思考過程、普通の回答、10案の下書き、内部評価は出力しない。
